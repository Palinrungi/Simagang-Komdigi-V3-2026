3. LANGKAH-LANGKAH EKSEKUSI DI SERVER PRODUCTION (3 STEP MUDAH)
--------------------------------------------------------------------------------

STEP 1 — SALIN / TIMPA 9 FOLDER DI ATAS KE PRODUCTION
- Ekstrak ZIP update ini di folder sementara, lalu copy-paste 9 folder di atas 
  ke direktori root project Laravel Anda.
- Atau jika menggunakan terminal Linux, perintah salin (dari folder ekstrak):
  
      cp -r app/Exports /path/to/production/app/
      cp -r app/Http/Controllers /path/to/production/app/Http/
      cp -r app/Models /path/to/production/app/
      cp -r app/Providers /path/to/production/app/
      cp -r database/migrations /path/to/production/database/
      cp -r resources/views /path/to/production/resources/
      cp -r routes /path/to/production/
      cp -r storage/app/public/images /path/to/production/storage/app/public/
      cp -r storage/app/releases /path/to/production/storage/app/

STEP 2 — JALANKAN DATABASE MIGRATION (WAJIB)
- Masuk ke folder root Laravel production Anda, lalu jalankan perintah berikut 
  untuk membuat tabel baru `positions`:
  
      php artisan migrate --force

STEP 3 — BERSIHKAN CACHE APLIKASI (WAJIB)
- Bersihkan cache agar rute dan tampilan baru langsung aktif di browser:
  
      php artisan route:clear
      php artisan view:clear
      php artisan config:clear
